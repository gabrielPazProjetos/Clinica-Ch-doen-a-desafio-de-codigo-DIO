#  Desafio DIO: Simulação de Clínica em HTML

Este projeto foi desenvolvido como parte da formação HTML da DIO. O desafio consiste em criar um site simples simulando uma clínica, utilizando apenas HTML, sem CSS por enquanto.

##  Estrutura do Projeto

O site é composto por quatro páginas:

- Página Inicial – Apresentação geral da clínica
- Sobre a Clínica – Informações institucionais e objetivos
- Horários – Tabela ou descrição dos horários de atendimento
- Contato – Formas de contato


Cada página possui:

- Uma imagem no cabeçalho (<header>)
- Conteúdo específico logo abaixo

##  Como Executar

Para visualizar o projeto:
-- Meu caso
1. Abra o projeto no Visual Studio Code
2. Clique com o botão direito no arquivo desejado
3. Selecione **Reveal in File Explorer**
4. Dê um duplo clique no arquivo HTML para abri-lo no navegador (testado no Microsoft Edge)

O site foi executado como esperado e apresentou o resultado conforme o planejado.
